Halftone printing builds an image from dots of one ink colour. Larger or denser dots read as darker areas, smaller or sparser dots as lighter areas. For display type, the same look needs no image at all: a repeating radial gradient creates the dots, and `background-clip: text` limits them to the shape of the letters.

The heading in the example stays real text. Screen readers announce it, you can select and copy it, and search engines index it. Only its fill changes.

## How the pattern works

One dot is a `radial-gradient()` that's solid ink up to the dot radius and transparent half a pixel later. The half pixel softens the edge, so the dots don't look jagged:

```css
background-image: radial-gradient(
  circle at center,
  var(--ink) var(--dot-radius),
  transparent calc(var(--dot-radius) + 0.5px)
);
background-size: var(--dot-spacing) var(--dot-spacing);
```

`background-size` sets the size of one cell, and the background repeats that cell in both directions. The dot spacing is therefore the cell size, and the dot radius must stay below half of it. At half the cell size, neighbouring dots touch and the pattern turns into a solid fill with small holes. The example clamps the radius in its controls and again in `index.js`.

To clip the pattern to the glyphs, the text colour becomes transparent and the background is clipped to the text:

```css
background-clip: text;
color: transparent;
```

## Keep a readable fallback

Transparent text without a clipped background is invisible. The example only sets `color: transparent` inside an `@supports` block, so a browser without `background-clip: text` shows solid text in the ink colour. The "Solid text" control switches to the same fallback on purpose, which is useful for comparing the two.

Contrast is the other risk. The dots cover only part of each glyph, so the effective contrast of halftone text is lower than the contrast of the ink colour alone. Use the effect for large display type, keep the ink dark on a light paper colour (or the reverse), and don't use it for body text.

## Motion

The "Animate" control moves the pattern diagonally by one cell, which makes it loop without a visible jump. The animation only runs when your system doesn't request reduced motion, it pauses with the "Pause animation" control, and it also pauses while the preview is scrolled out of view.

## Stripes instead of dots

The same technique works with any gradient. A `repeating-linear-gradient()` fills the glyphs with stripes, and unlike the dot pattern, its angle visibly changes the result:

<CodePlayground leaf="2026/halftone-typography-with-css" example="stripes" />

Each repeat is one stripe of ink followed by a transparent gap. The animation moves the stripes by one repeat, which needs a registered custom property: `@property` gives `--stripe-offset` a `<length>` type, so the browser can interpolate it.

## About the examples

You can edit the HTML, CSS, JavaScript, and the state file of each example. The controls change only `playground-state.json`, and `index.js` applies that state as CSS custom properties and as the heading text. Because the state is an ordinary file, copying the files gives you exactly what you see. The preview runs in a sandboxed frame without network access, so it can't load remote fonts or images.

The address bar records every setting you change: the link holds only the values that differ from the defaults, so you can bookmark it or send it to someone, and the "Copy link" button copies it. Code edits aren't part of the link.

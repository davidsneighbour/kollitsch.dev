# Check title

## Purpose

State the outcome and stable selection ID (the filename).

## Input

Name the required post data, rules, sources, tools, and any dependencies.

## Verify

List concrete invariants; distinguish mandatory rules from recommendations.

## Method

Give the narrowest supported command or manual procedure and its coverage limits. Define how unavailable prerequisites are reported. Do not copy the schema or invent tool flags.

## Output

Use the shared result contract and name any additional evidence needed.

## Pass/fail

Define errors, warnings, blockers, and not-applicable cases.

## Remediation

Name permitted fixes, required decisions, validation after edits, and any detailed procedure resource.
